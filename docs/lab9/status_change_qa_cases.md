# ЛР №9. Набор ручных тест-кейсов «Смена статуса заявки» (SC-01…SC-31)

Источник: `docs/TZ.md` (ФТ-2, ФТ-6, ФТ-7, ФТ-9, ФТ-10, НФТ-2, НФТ-3, критерий приёмки 3), таблица «Правила ролей» из README и данные тестовой БД. Набор подготовлен нейросетью по запросу студентки (запись AI-журнала ЛР №9, запись 1), затем отревьюирован отдельным запросом (запись 2) и запущен на реальном приложении.

**Условия.** Все кейсы выполняются на свежей БД из `db/schema.sql` и `db/seed.sql`. Статусы: 1 Новая, 2 В работе, 3 Выполнена, 4 Закрыта. Смена статуса: `PATCH /api/requests/{id}` с телом `{"status_id": N}`.

**Заявки в тестовой БД.** №1 Новая (ivanov, без исполнителя); №2 В работе (ivanov, petrov); №3 Выполнена (sokolova, petrov); №4 Закрыта (ivanov, morozov); №5 Новая (sokolova); №6 Новая (ivanov); №7 В работе (sokolova, morozov); №8 Новая (sokolova); №9 Выполнена (ivanov, morozov); №10 В работе (sokolova, petrov).

| SC-09 | Фильтр по статусу видит заявку после смены (ФТ-10) | Выполнен SC-02 | admin: `GET /api/requests?status_id=3` | 200; в списке есть заявка №2, нет заявок с другим статусом | Medium |
