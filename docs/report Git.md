«Управление версионированием проекта осуществлялось через графический клиент GitHub Desktop. Соответствие выполненных визуальных операций базовым командам Git:
1. Фиксация изменений в ветке — эквивалент ⁠git commit -m⁠.
2. Создание и переключение на ветку develop — эквивалент ⁠git checkout -b develop⁠.
3. Слияние веток при релизе — эквивалент ⁠git merge develop⁠.
4. Синхронизация с удаленным сервером — эквивалент ⁠git push origin⁠».
