TC-11 — Управляющий символ NUL в теме заявки
Ожидается: HTTP 422 (ввод отклонён, ошибка сервера недопустима)
Фактически: HTTP 422: Поле «Тема» содержит недопустимые управляющие символы
Статус: PASS

> POST /api/requests   [operator]
> тело: {'title': 'до\x00после', 'category_id': 3, 'priority': 'Высокий', 'applicant_id': 5}
< HTTP 422
< {"error":{"code":"validation_error","message":"Поле «Тема» содержит недопустимые управляющие символы","details":{"title":"invalid_characters"}}}
