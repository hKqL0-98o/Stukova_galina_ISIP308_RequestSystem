## 5. Известные ограничения и непроверенное

- 31 ручной кейс выполнен HTTP-запросами с cookie-сессией. Внешний вид страниц и подтверждение удаления дополнительно проверены 15.11.2026 в браузере Chrome (сценарий входа, создания, назначения, смены статуса, комментария, закрытия и удаления); скриншоты в `docs/screenshots/lab6_10/`. Эта проверка и выявила BUG-04.
- Не проверялись: производительность (НФТ-3: отклик ≤ 3 с), одновременная работа нескольких пользователей, другие браузеры и мобильная вёрстка, нагрузочное тестирование. Работа в Docker и на удалённой ВМ проверена 17.11.2026 (`docs/lab8/deploy_report.md`): `/health`, `/docs`, вход, сохранение базы после перезапуска контейнера.
- Формы не защищены CSRF-токеном (см. замечания в `bug_reports.md`); для учебного проекта оставлено как известное ограничение.
- Автотесты используют тестовый пароль во временной БД, рабочие учётные записи не проверялись.
- Расхождение с ТЗ, которое не исправлялось: оператор может менять статус заявки (по ТЗ статусы меняет исполнитель; README это разрешает). Выявлено исследовательской проверкой X-02 (`docs/lab9/status_change_qa_review.md`).
